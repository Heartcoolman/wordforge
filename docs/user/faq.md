# 常见问题（FAQ）

## 注册与登录

**注册时提示"该邮箱已被注册"**

同一邮箱只能注册一个账号。如果忘记密码，使用"忘记密码"功能重置，而不是重新注册。

**注册时提示"注册功能已关闭"或"用户注册数量已达上限"**

这是管理员在系统设置中启用了限制。请联系服务器管理员获取邀请或增加名额。

**登录后立即退出 / Token 失效**

原因通常是 JWT 密钥已轮换（服务器重新生成了密钥）。退出登录后重新登录即可，旧 Token 会失效属于正常行为。

**忘记密码怎么办**

1. 在登录页点击"忘记密码"
2. 输入注册邮箱，系统会发送重置链接
3. 点击链接后设置新密码（链接有效期有限，过期需重新申请）

## 学习数据同步

**换设备后学习记录消失**

WordForge 的学习记录存储在服务器，登录同一账号即可在任何设备恢复。如果记录仍未显示：
- 确认登录的是同一个账号（邮箱相同）
- 检查是否连接了正确的服务器地址
- 下拉刷新页面

**学习进度没有保存**

每次答题结果会实时上报后端。如果答题后立即关闭 App，可能有最后一条记录丢失。确保答题后等待页面切换完成再关闭。

网络断开时，客户端会缓存记录并在恢复连接后重新上报，但需要客户端保持在前台。

**AMAS 推荐的单词感觉重复**

AMAS 根据遗忘概率和 ELO 难度匹配选词，复现率高的单词意味着算法判断你对该词的记忆还不稳固。建议坚持按推荐顺序学习，随着正确率提升，复现间隔会自动拉长。

## 账号管理

**如何修改用户名**

在客户端"个人设置"中可以修改用户名。用户名有格式限制，不允许特殊字符。

**如何修改密码**

在"个人设置 → 安全"中可以修改密码。需要输入当前密码进行验证。

**如何注销账号**

账号注销会永久删除你的所有数据（学习记录、词书、收藏、备注等），**无法恢复**。

如需注销，在客户端"设置 → 账号 → 注销账号"中操作，或联系管理员代为删除。

如需在注销前导出数据，请先参考[隐私与数据](./privacy)中的数据导出说明。

## 客户端问题

**页面一直加载中**

1. 检查网络连接
2. 确认服务器正常运行：访问 `https://your-server.example.com/health`，会返回一个含 `status` 字段的 JSON 对象，`status` 取值可为 `ok` / `degraded` / `down`。其中 `degraded`（降级）表示部分非核心组件异常，但服务仍可正常使用，不要误判为故障。只要 HTTP 返回 200 且能拿到 JSON，即说明服务可达。
3. 清除浏览器缓存 / 重新安装 App

**收到"系统正在维护中"提示**

服务器管理员开启了维护模式，正在进行升级或修复。通常几分钟到几小时内恢复，可稍后重试。

**疲劳检测摄像头权限问题**

首次使用疲劳检测功能时，浏览器 / 系统会请求摄像头权限。如果不授权，功能自动降级为不检测疲劳信号，不影响正常学习。

如已拒绝且想重新开启，在浏览器地址栏点击"锁"图标 → 权限 → 摄像头 → 允许，然后刷新页面。

## 安全与账号风险

**提示"设备被标记风险"或被封禁怎么办**

WordForge 对 Web 端启用了设备指纹封禁，用于在不依赖账号的前提下拦截违规设备。其判定分两档：

- **强指纹精确命中**：设备特征足够独特、与已封禁设备精确匹配时，直接封禁。
- **低熵指纹（特征不够独特）**：不直接封，而是进入**风险复核队列**，由管理员在后台逐条复核，确认后才封禁或解除标记。

如果你认为自己被误判（例如与他人共用网络、使用了隐私 / 指纹保护浏览器导致特征雷同），请联系服务器管理员说明情况。管理员可在后台复核队列中核实并解除标记。换浏览器、隐私模式或更换设备可能改变指纹，但对已精确命中的封禁不一定有效，且重复绕过会增加被再次标记的概率——正确做法是走管理员复核解除。

## 资源包与内容更新

**资源包 / 内容更新没生效或失败怎么办**

资源包是「内容热更」机制（运营在不发版的前提下更新公告、文案、远程开关等，详见[资源包热更](/resource-packs)）。如果更新没生效或安装失败，按以下顺序排查：

1. **检查网络**：内容更新依赖客户端在线拉取与下载。离线设备只能在下次冷启动联网时才会拿到新内容；「秒级生效」仅对在线、当时收到推送（SSE）的设备成立。
2. **检查后端版本与门控**：部分资源包带 `minAppVersion` 门控，客户端版本过低会被服务端跳过。请升级到本次目标版本后重试。
3. **验签失败**：客户端用硬编码的生产公钥验签，**本地 / 测试后端用的是开发密钥，签出的包在生产客户端验签必然失败**。请确认连接的是生产后端（默认 `http://8.135.57.148/`），不要用本地后端签的包测生产客户端。
4. **冷启动重试**：完全退出并重新打开 App，触发一次主动检查。

**之前下载的内容被"停用"后，App 里还显示着，是不是出错了？**

不是。资源包「停用」是**软删除**：只把该版本从服务端摘除，**不会远程擦除已安装设备上的内容**。客户端内容来自本地缓存，停用后设备保持现状属正常行为。要真正撤回内容，运营需发布并激活一个覆盖用的新版本，靠客户端下次检查替换。
